GOLDEN TIDE — a sun-soaked open-world crime game set in Solara Bay, a golden-hour coastal city sliding into neon dusk. Play Rio, a getaway driver pulled back into the underworld, and take on Don Alvaro Voss across 10 story jobs in 5 districts: beachfront getaways, a marina heist, dockside ambushes, a sunset grand prix, a casino vault and a final showdown on the pier as the tide comes in. Drive and steal cars, fight with a four-tier weapon wheel, dodge a five-star police force with roadblocks, spike strips and the GOLDEN-1 helicopter, upgrade your ride at the Solara Garage, run taxi and delivery side jobs, and tune in to three procedural radio stations. Built with three.js, fully offline, no network requests.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Or serve `game/` with any static file server.
